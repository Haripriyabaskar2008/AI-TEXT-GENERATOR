# AI-TEXT-GENERATOR
#              AI Text Generator

An AI-powered text generation application built using **Python, Streamlit, Hugging Face Transformers, and GPT-Neo 125M**.

This application allows users to enter a text prompt and generate AI-powered text based on the given input through a simple and interactive web interface.

## ✨ Features

-  AI-powered text generation
-  Simple and user-friendly interface
-  Uses Hugging Face Transformers
-  Interactive Streamlit web application
-  Generates text based on user prompts
-  Easy to install and run locally
-  Useful for learning and experimenting with AI text generation

## Technologies Used

- **Python**
- **Streamlit**
- **Hugging Face Transformers**
- **PyTorch**
- **GPT-Neo 125M**
